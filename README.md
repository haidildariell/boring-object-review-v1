## Entry

This coaster has one job — catch the ring — and after five years under the same mug it wears a perfect brown circle like a medal it never asked for.

## How it works

Run `python3 main.py`. The program writes the review above, exactly as-is,
as a single line to `/output/entry.txt` (creating `/output` if needed).
No network, no external files, no randomness — the output is deterministic.
The entry is 148 characters, one line, UTF-8, with no trailing newline.
